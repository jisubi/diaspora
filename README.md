# Diaspora

Concept site for a nonprofit serving Korean families sent to Latin America in 1905 and their descendants, many still living in poverty across Mexico, Cuba, Guatemala and Brazil.

Static single-page mock. No backend — the giving CTA is non-functional by design.

- `public/index.html` — the whole site
- `public/img/` — imagery (Wikimedia Commons, illustrative only)

Deployed on Vercel as a static site.
